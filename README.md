# Teen Budget Tracker

A sleek, visual financial dashboard built for students or teens to track their savings goals, calculate realistic timelines, and manage their allowance without the bloat of adult banking apps.
---
## Features
* **Progress Tracking:** Input your current savings and total goal cost to see a live visual progress bar.
* **Smart Financial Breakdown:** Automatically calculates your remaining balance and breaks down your daily savings target.
* **Dynamic Status Cards:** Updates your financial status in real-time based on how close you are to your goal.
* **Sleek Dark Mode Design:** A modern UI crafted for readability and ease of use.
---

## Built With
* **HTML:** For the structured semantic layout and input dashboard.
* **CSS:** Custom grid systems, responsive layouts, and smooth progress bar animations.
* **JavaScript:** Core logical processing, string formatting, and dynamic DOM manipulation.

---


## My Development Journey
I built this project to learn the core foundations of web development. Over the course of this build, I practiced:
1. Connecting HTML input fields to JavaScript using `document.getElementById`.
2. Handling data validation to prevent math breaks (like handling `NaN` or dividing by zero).
3. Modifying CSS styles dynamically through JavaScript (`element.style.width`) to animate layouts in real-time.
---
## Installation & Local Setup
To run this project locally:
1. Clone or download this repository.
2. Open the `index.html` file directly in any modern web browser.
3. Start tracking your savings!
